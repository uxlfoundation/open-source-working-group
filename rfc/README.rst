Requests for Comments
=====================

Use an RFC for a significant change spanning UXL specifications, projects or
shared infrastructure. Start with the `RFC template <template.md>`_ and open a
pull request in this directory. Use the next unused three-digit number and a
short descriptive filename. Identify the proposal owner, motivation, affected
projects, alternatives, migration impact and unresolved questions.

Ask the Working Group maintainers for review. Maintainers apply the ``RFC``
label when the proposal is ready for discussion. Record the decision and a link
to the approving meeting or PR before describing a proposal as accepted. Keep
superseded proposals accessible with a status note rather than deleting them.
